# Agent guidance for Bramblepost

This is agent guidance for this repo (for Codex and other non-Claude agents). It mirrors the rules in CLAUDE.md.

## Story secrecy (standing rule)
- The project owner (Caroline) wants to experience Bramblepost's story for the first time by playing the full game on `main` after a main release.
- Never tell her any story content (plot, secrets, character reveals, new names, quotes or paraphrase) in chat, PR titles or descriptions, issue titles, commit messages, review comments, status reports or notes.
- Report story work only in structural terms, e.g. "story text for routes 1-5 is in review; 2 blocking issues about branching".
- Preview play-throughs (develop, release branches, local and phone previews) must show only the placeholder content.
- When story work needs a decision, route it to the dispatcher, who decides without involving her.
- Work against the placeholder (stand-in) content wherever possible. Don't open spoiler-bearing story files unless your task truly requires it.
